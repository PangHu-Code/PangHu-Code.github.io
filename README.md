# 欢迎

基于 FlClash 二次开发的加速器客户端，支持 Android、macOS、Windows 三端。

---

## 核心特性

- 全局配置 OSS 拉取，支持多 OSS 轮询
- 支持多 API 轮询
- 订阅地址轮询（需更改后端服务）
- 多平台风格样式统一
- 多主题色自定义
- 系统代理开关 / TUN 模式 / 网络检测
- 自定义套餐内容：支持潮汐客户端格式、支持 HTML
